# Backend (Module 01 Skeleton)

FastAPI skeleton for `01_文档解析与结构化`.

## Scope

- Document parse task lifecycle skeleton.
- Multi-format parser adapter interface and placeholders.
- Structured output schema for downstream chunking.
- Basic API and tests.

## Run

```powershell
pip install -r requirements.txt
uvicorn app.main:app --reload --app-dir .
```

## Test

```powershell
pytest
```
