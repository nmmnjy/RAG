- 当前真实联调结果以拒答为主（`QA_CONTEXT_EMPTY`），原因是本地知识库证据不足；可答场景需补充有效文档数据后验证 citation 非空路径。

## 实际联调结果（本轮）
- 联调请求：
  - `POST http://localhost:8000/api/v1/qa/answers`
  - body：`{ kb_id: "kb_hr", query_text: "测试问题", top_k: 5 }`
- 实际响应：
  - HTTP `200`
  - `code = "OK"`
  - `data.answer` 有值
  - `data.citations = []`
  - `data.confidence = 0.0`
  - `data.refuse_reason = "QA_CONTEXT_EMPTY"`
- 结论：
  - `/qa` 页面可使用真实后端返回正常展示 `answer/citations/confidence/refuse_reason`。
  - 已移除对 fallback 成功路径的依赖。
  - 参数链路已打通：可通过前端控制 `top_k/vector_top_k/keyword_top_k/enable_rerank` 并随请求发送。
  - 第三轮确认：超时/网络失败可见提示已生效，不存在“无反应”状态。
