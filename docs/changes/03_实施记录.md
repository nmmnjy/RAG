## 风险与未覆盖项
- 当前默认 provider 为 mock，不代表真实模型效果与线上延迟。
- 仓储当前为内存实现，未覆盖持久化、并发控制、事务与重试。
- 尚未接入任务编排层（worker）与 API 暴露层，仅完成 schema + service + repository 骨架。
- 尚未进行性能压测与模型选型对比（任务 03 后续项）。
- `OpenAICompatibleEmbeddingProvider` 与 `PgVectorRepository` 当前仅完成接入边界，尚未接通真实 SDK/数据库操作。
- 尚未覆盖真实仓储的连接池、事务、批量 upsert SQL、索引管理与重试策略。
- 尚未覆盖真实 embedding provider 的限流、超时、批量切分与可观测性日志。
- 当前真实调用基于 OpenAI-compatible HTTP 协议，尚未覆盖流控重试、退避策略与熔断保护。
- 运行期 fallback 到 mock 时，检索质量会下降（功能可用优先，效果不保证）。
- repository 当前仍是内存实现，`VECTOR_*` 错误码在真实仓储接入后价值更高，现阶段主要用于流程收敛。
