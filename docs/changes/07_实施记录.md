## 风险与未覆盖项
- 当前为样例数据 + mock provider + 规则评测，未覆盖真实线上分布与时延指标。
- 当前门禁仅实现最小规则骨架（通过率与维度必过），未覆盖趋势回归与多版本对比。
- 当前报告输出为离线 JSON 文件，未接入统一任务平台与可视化看板。
- 可答样本检查目前为字符串包含匹配（`answer` 或 `citation.snippet` 命中 `evidence_text`），尚未做语义同义归一与多证据聚合评分。
- 当前可答回归仍依赖 mock provider，后续接入真实模型后需重新标定 `min_answer_confidence`。
- embedding fallback 目前通过 active provider 推断；若后续 provider 实现升级，建议补充显式 fallback 事件字段以增强可追踪性。
- `gate_pass_rate_min` 当前走命令参数注入；若后续引入统一配置中心，需同步定义“配置优先级（CLI > 配置 > 默认值）”。
- 可答演示样本当前依赖 mock/provider 与占位解析文本，不能代表真实生产问答质量上限。
- 可答演示样本当前依赖 mock/provider 与测试注入结构化数据，不能代表真实生产问答质量上限。
