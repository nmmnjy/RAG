## 风险与待确认项
- 风险：
  - 当前主链路索引为内存实现，进程重启后会丢失。
  - 当前 `OpenAICompatibleLLMProvider` 尚未接入真实 HTTP/SDK 调用，仍处于接入位骨架阶段。
  - 当前仍以 mock 作为默认与 fallback 生成，未覆盖真实 LLM 质量与延迟表现。
  - `qa_pipeline_service` 每次问答前执行索引同步，文档规模增大后需优化增量策略。
  - confidence 为规则融合值，未经过评测标定。
- 待确认项：
  - `QA_EVIDENCE_INSUFFICIENT` 是否纳入 00 全局错误码规范。
  - citation 是否在 04/05 基线层面强制页码字段。
  - 当前可答样本通过测试注入 `structured_document` 驱动；后续接入真实文件解析输入后，需要补一条“真实文件源”回归用例。
  - 真实接入阶段的首选 provider 协议（OpenAI SDK / OpenAI-compatible HTTP）与统一重试策略。
