## 风险与待确认项
- 风险：
  - 当前主链路索引为内存实现，进程重启后会丢失。
  - 当前走 OpenAI-compatible HTTP 协议，未锁定具体厂商 SDK，部分厂商响应细节可能需适配。
  - 当前仍以 mock 作为默认与 fallback，真实 provider 故障时可能被 fallback 掩盖，需要配套告警。
  - `qa_pipeline_service` 每次问答前执行索引同步，文档规模增大后需优化增量策略。
  - confidence 为规则融合值，未经过评测标定。
  - 当前 `QA_LLM_PROVIDER_ERROR/QA_CITATION_MISSING` 为模块内拒答码，尚未纳入 00 全局错误码清单。
- 待确认项：
  - `QA_EVIDENCE_INSUFFICIENT` 是否纳入 00 全局错误码规范。
  - citation 是否在 04/05 基线层面强制页码字段。
  - 当前可答样本通过测试注入 `structured_document` 驱动；后续接入真实文件解析输入后，需要补一条“真实文件源”回归用例。
  - 是否在下一轮引入重试/退避与可观测指标（provider_error_rate、fallback_rate）。
