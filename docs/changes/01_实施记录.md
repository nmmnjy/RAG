## 风险与阻塞
- 当前解析适配器为占位实现，尚未接入真实文件抽取库，复杂版式解析能力未覆盖
- 仓储层当前为内存实现，服务重启会丢失任务状态
- 尚未接入网关透传时，`request_id/trace_id` 由服务端兜底生成
- `source` 到 `file_path` 目前采用轻量解析规则（`file://` 或绝对路径），后续需与上传存储策略对齐
- `pdf/word/excel` 仍是 placeholder，真实解析质量验证尚未开始
- 上传接口当前采用 base64 JSON 形式，后续若切 multipart 需评估前端与网关改造成本
- `DOC_PARSE_UPLOAD_DIR` 当前落本地磁盘，分布式部署需要共享存储或对象存储抽象
