## 风险与阻塞
- 历史分支或未合并分支中可能仍存在 `ops/*` 路径引用，合并时需再做一次全仓扫描。
- 当前为目录与文档收敛，不包含真实上线验证，部署可用性仍依赖后续环境接入。
- 本地一键检查依赖开发机已有 Node/Python 与依赖安装；若环境未准备好会导致脚本失败。
- 离线评测结果受样本数据和 mock provider 影响，不代表生产质量上限。
- real 模式是否发生 fallback 受外部 provider 可用性、网络、配额与鉴权状态影响。
