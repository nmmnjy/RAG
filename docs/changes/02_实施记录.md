## 风险与未覆盖
- 当前 token 统计为近似空格分词，未接入真实 tokenizer。
- 列表/代码块识别依赖文本模式，精度受上游结构化质量影响。
- 尚未接入 API/任务编排层，仅完成服务层与 schema 层骨架。
- `sentence_boundary_fallback_split` 当前为规则切分，未做语言学级断句与跨语种优化。
- markdown 代码块聚合在“缺失闭合 fence”场景会回退普通文本路径，极端输入下仍可能出现边界噪声。
