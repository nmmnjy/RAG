# 02 语义分块策略

## 模块目标
设计并验证长文档语义分块策略，提升上下文完整性与后续检索效果。

## 范围边界
- 包含：分块算法候选、参数方案、质量评测方法。
- 不含：向量检索与答案生成实现。

## 关键任务清单
1. 分块策略候选对比
- 标题层级优先切分。
- 语义窗口切分。
- 固定 token + overlap 混合切分。

2. 参数设计
- chunk 长度、overlap 长度、最小段落长度。
- 特殊结构处理（表格、列表、代码块）。

3. 评测方案
- 上下文完整性评分。
- 检索命中率贡献分析。
- 切分稳定性与性能开销评估。

4. 策略版本化
- 分块策略版本号与回溯机制。

## 交付物
- 分块策略设计文档。
- 参数推荐表（默认值与调优范围）。
- 评测基线与结果记录模板。

## 验收标准
1. 分块后文本可读性与语义连续性满足评测阈值。
2. 对检索 Top-5 命中率有正向贡献。
3. 策略可版本化、可回滚。

## 依赖与风险
- 依赖：01 模块结构化输出。
- 风险：不同文档类型需差异化参数。
