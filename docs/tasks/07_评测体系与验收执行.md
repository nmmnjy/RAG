# 07 评测体系与验收执行

## 模块目标
建立统一评测数据、指标体系与验收执行机制，形成可持续优化闭环。

## 范围边界
- 包含：评测集构建、自动化评测方案、验收报告模板、发布门禁规则。
- 不含：线上运维告警实现。

## 关键任务清单
1. 评测集建设
- 按业务主题构建问题集与标准答案/证据集。
- 覆盖常见问答、长文档问答、边界问答场景。

2. 指标体系定义
- 检索：命中率、MRR、Recall@K。
- 生成：可追溯率、无依据回答率、拒答准确率。
- 性能：P95 延迟、接口可用性。

3. 自动化评测流程
- 设计离线回归评测流程与报告输出格式。
- 定义评测触发时机（版本变更、策略变更）。

4. 验收与门禁
- 定义上线前最低验收阈值。
- 未达标项阻断发布并给出回退建议。

## 交付物
- 评测指标定义文档。
- 自动化评测执行方案。
- 验收报告模板与门禁规则。

## 验收标准
1. 可复现输出评测结果与趋势对比。
2. 验收标准与 PRD 指标一致。
3. 发布门禁规则明确且可执行。

## 依赖与风险
- 依赖：04、05 模块提供稳定输出。
- 风险：评测样本覆盖不足导致指标失真。
