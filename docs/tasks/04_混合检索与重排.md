# 04 混合检索与重排

## 模块目标
设计语义检索与关键词检索融合方案，提升召回质量并支持可插拔重排。

## 范围边界
- 包含：召回融合、分数归一化、重排接口、评测集定义。
- 不含：最终答案生成实现。

## 关键任务清单
1. 双路召回设计
- 向量检索与关键词检索并行召回。
- 统一召回结果结构。

2. 融合与归一化
- 设计分数归一化方法与融合权重策略。
- 支持按知识库或场景配置权重。

3. 重排接口设计
- 定义可插拔重排接口输入输出。
- 预留轻量重排与模型重排扩展能力。

4. 效果评测方案
- 构建离线评测集。
- 对比纯关键词、纯语义、混合检索指标。

## 交付物
- 混合检索架构方案。
- 重排接口定义文档。
- 离线评测方案与调优参数表。

## 验收标准
1. 混合检索 Top-5 命中率较纯关键词提升 >= 20%。
2. 检索结果结构符合统一字段约定。
3. 融合参数可配置、可回放评测。

## 依赖与风险
- 依赖：03 模块向量能力与关键词索引能力。
- 风险：不同语料分布导致融合权重迁移性不足。
