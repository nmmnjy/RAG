# 03 向量化与向量存储

## 模块目标
确定文本向量化模型与向量存储方案，建立可替换、可扩展的向量能力。

## 范围边界
- 包含：轻量模型选型、向量表结构、写入更新策略、性能测试计划。
- 不含：混合检索融合策略实现。

## 关键任务清单
1. 模型选型对比
- 对比候选轻量 embedding 模型在效果、速度、资源占用上的表现。
- 明确默认模型与备选模型切换机制。

2. 向量存储设计
- 设计 Supabase/pgvector 表结构与索引策略。
- 约定向量维度、版本字段、元数据关联关系。

3. 向量写入与更新流程
- 首次构建、增量更新、重建流程设计。
- 幂等与失败重试机制。

4. 性能评测计划
- 写入吞吐、查询延迟、存储占用评测口径。

## 交付物
- 模型选型报告。
- 向量存储结构设计文档。
- 向量写入/更新流程文档与性能测试计划。

## 验收标准
1. 向量写入流程稳定且支持失败重试。
2. 向量查询延迟满足后续检索目标。
3. 模型替换不影响上层接口。

## 依赖与风险
- 依赖：02 模块分块输出。
- 风险：模型效果与资源成本的权衡。
