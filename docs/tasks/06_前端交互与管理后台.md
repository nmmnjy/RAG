# 06 前端交互与管理后台

## 模块目标
定义用户侧问答与管理侧知识运营流程，确保操作清晰、状态可见、结果可追踪。

## 范围边界
- 包含：页面信息架构、状态流转、核心页面规范、组件复用规范。
- 不含：后端算法实现。

## 关键任务清单
1. 信息架构设计
- 用户端：问答页、历史页、引用查看。
- 管理端：知识库管理、文档管理、任务状态、日志看板。

2. 页面状态流转
- 上传、解析、索引构建、检索、回答状态定义。
- 错误态与空态规范。

3. UI 组件规范
- 基于 shadcn/ui 约定复用组件库。
- 定义表单、表格、提示、反馈组件使用规范。

4. 交互细节
- 引用跳转、答案置信度展示、用户反馈入口。

## 交付物
- 页面清单与线框说明。
- 交互状态机说明。
- 组件复用规范。

## 验收标准
1. 核心流程页面覆盖完整。
2. 关键状态可视化清晰。
3. 用户可直接定位答案来源引用。

## 依赖与风险
- 依赖：00 模块接口规范与 05 模块输出协议。
- 风险：多状态并存导致前端复杂度上升。
