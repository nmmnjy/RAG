# 05 答案生成与溯源

## 模块目标
基于检索上下文生成可靠答案，并保证引用可追溯和不确定场景可拒答。

## 范围边界
- 包含：Prompt 模板、拒答规则、引用拼接规范、质量评估标准。
- 不含：前端页面实现。

## 关键任务清单
1. 生成链路设计
- 定义检索结果到 LLM 输入的上下文拼接规则。
- 控制上下文长度与引用映射关系。

2. Prompt 与输出协议
- 设计系统提示词模板与输出 JSON 协议。
- 标准化 `answer/citations/confidence/refuse_reason` 字段。

3. 拒答与风控规则
- 无充分证据时触发拒答。
- 低置信度输出风险提示。

4. 质量评估
- 幻觉率、引用有效率、可读性与一致性评估。

## 交付物
- 生成链路设计文档。
- Prompt 模板与输出协议文档。
- 质量检查清单。

## 验收标准
1. 问答可追溯率 = 100%。
2. 无依据回答率 <= 5%。
3. 拒答规则可配置并可审计。

## 依赖与风险
- 依赖：04 模块检索结果质量。
- 风险：上下文噪声导致答案偏差。
