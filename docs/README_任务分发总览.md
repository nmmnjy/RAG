# 任务分发总览（V1）

## 使用说明
- 本目录用于主线程向子线程分发任务。
- 每个模块一个独立任务文档，子线程按文档执行并回传交付物。
- 从现在开始，关键产出必须同步落到仓库文档中。
- 任务分发与执行必须同时参考 `tasks`、`specs` 和 `changes` 三类文档。

## 文档分层
- `docs/tasks`：模块任务清单，定义目标、边界、交付物和验收。
- `docs/specs`：模块共享规范，作为跨线程引用基线。
- `docs/changes`：模块实施记录，记录本轮实现、变更、风险与下一步。

## 推荐分发顺序
1. 先发：00（统一规范）
2. 编码首批并行：01、06、08
3. 待 01 产出稳定结构化输出后，再推进 02、03
4. 待 03 稳定后，再推进 04、05、07
5. 每日汇总：由主线程按 PRD 指标与共享文档校验输出一致性

## 统一验收口径
- 以 `docs/PRD_V1_企业知识库智能问答系统.md` 的指标为准。
- 子线程交付必须包含：产出物、风险项、待协同项、是否满足验收项。
- 任何影响其他线程的改动，必须先写入 `docs/specs` 或 `docs/changes`。
