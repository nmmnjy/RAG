# 任务分发总览（V1）

## 使用说明
- 本目录用于主线程向子线程分发任务。
- 每个模块一个独立 MD，子线程按文档执行并回传交付物。
- 当前阶段仅做技术栈与工程框架落地，不实现核心业务代码。

## 推荐分发顺序
1. 先发：00（统一规范）
2. 并行发：01、02、03、04、05、06、07、08
3. 每日汇总：由主线程按 PRD 指标校验输出物一致性

## 统一验收口径
- 以 `docs/PRD_V1_企业知识库智能问答系统.md` 的指标为准。
- 子线程交付必须包含：产出物、风险项、待协同项、是否满足验收项。
