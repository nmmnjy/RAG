# 冻结后路线图（V1）

## 当前冻结基线
- 冻结日期：2026-03-29
- 验收状态：`00~08` 全模块通过
- 当前结论：V1 可用版可本地启动、可完成基础问答闭环、可执行离线评测与一键验收

## 恢复后第一轮计划（P0）
目标：恢复开发后先保证“真实链路可控”，不做大范围重构。

1. 真实 Provider 小范围联调（Embedding + LLM）
- 进入条件：有效 API Key、可访问外网模型服务
- 完成标准：
  - real-mode 预检通过
  - `local-real-acceptance` 可稳定产出报告
  - `provider_runtime` 可见且门禁行为符合预期

2. QA 体验稳定性修正
- 进入条件：前后端本地启动稳定
- 完成标准：
  - 问答请求无“无响应”状态
  - 失败提示可见且可定位（超时、后端异常、无证据拒答）
  - 引用详情页字段可用且跳转稳定

3. 文档与脚本一致性巡检
- 进入条件：第一轮改动合并后
- 完成标准：
  - README 命令与 `infra/scripts` 参数一致
  - `docs/specs` 与 `docs/changes` 同步更新
  - 不新增 `ops/*` 路径

## 恢复后第二轮计划（P1）
目标：推进“准生产化能力”，优先解决可运维与可观测问题。

1. 向量存储真实落地（pgvector/Supabase）
- 进入条件：03 契约冻结保持不变
- 完成标准：
  - 可切换到真实向量库并完成写入/查询
  - 幂等 upsert 与重建/增量行为可验证
  - 错误码与重试策略生效

2. 评测门禁接入流水线
- 进入条件：07 离线评测稳定运行
- 完成标准：
  - CI 可执行离线评测命令
  - `release_blocked` 作为发布门禁
  - 稳定报告纳入版本基线

3. 运维巡检与回滚演练
- 进入条件：08 runbook 已冻结
- 完成标准：
  - 按 runbook 完成一次完整演练（发布 -> 健康检查 -> 回滚）
  - 关键观察项（可用性、5xx、P95）可追踪
