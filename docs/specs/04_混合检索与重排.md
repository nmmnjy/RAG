## 默认归一化与融合策略
- 归一化：`min-max`
  - 路径：`backend/app/services/hybrid_fusion.py`
  - 规则：
    - `norm = (x - min) / (max - min)`
    - 当 `max == min` 且分数大于 0，归一化后统一置 `1.0`
    - 当 `max == min` 且分数小于等于 0，归一化后统一置 `0.0`
- 融合：加权求和
  - 默认权重：
    - `vector_weight = 0.6`
    - `keyword_weight = 0.4`
  - 公式：
    - `score_final = vector_weight * score_vector_norm + keyword_weight * score_keyword_norm`

## 可插拔重排接口
- 接口位置：`backend/app/services/reranker.py`
- 抽象：`Reranker`
  - `rerank(request: RerankRequest) -> list[HybridRetrieveHit]`
- 默认实现：`NoopReranker`
  - 不改序，仅截断 `top_k`
- 扩展约束：
  - 重排器仅处理候选集排序，不改变 `chunk_id` 与核心分数字段语义

## 默认可运行流程（V1）
- 服务位置：`backend/app/services/hybrid_retrieval_service.py`
- 流程：
  1. 查询文本向量化（复用 03 provider）
  2. 语义召回：`VectorStoreService.query_similar(...) -> list[VectorQueryHit]`
  3. 关键词召回：`KeywordRetriever.search(...) -> list[KeywordQueryHit]`
  4. 分数归一化 + 融合
  5. 可选重排（默认 Noop）
  6. 输出稳定 `HybridRetrieveResult`
