# 05 答案生成与溯源

## 文档状态
- 状态：已进入设计 + 代码骨架实现
- 作用：消费 `04` 冻结的 `HybridRetrieveResult`，输出稳定问答结果：`answer/citations/confidence/refuse_reason`
- 依赖基线：
  - `docs/specs/00_项目框架与规范.md`
  - `docs/specs/04_混合检索与重排.md`

## 边界与约束
- 负责：
  - 答案生成输入/输出契约
  - 可替换 LLM provider 接口
  - 引用拼接与溯源结构
  - 有依据回答 / 无依据拒答规则
  - 默认可运行 mock 流程
- 不负责：
  - 改动 04 检索契约
  - 接入真实线上大模型
  - 前端渲染策略实现

## 输入契约（直接消费 04）
- Schema 位置：`backend/app/schemas/answer_generation.py`
- `AnswerGenerationRequest`
  - `kb_id`
  - `query_text`
  - `retrieval_result`（类型：`HybridRetrieveResult`）
  - `max_context_chunks`
  - `min_score_threshold`
  - `min_evidence_chunks`
  - `refusal_answer_text`

说明：
- `retrieval_result.hits[]` 直接使用 04 稳定字段，不新增第五套检索命中结构。

## 输出契约（稳定字段）
- Schema 位置：`backend/app/schemas/answer_generation.py`
- `AnswerGenerationResult`
  - `answer`
  - `citations`
  - `confidence`
  - `refuse_reason`
  - `debug`（内部调试，不影响前端主流程）

约束：
- 输出必须始终包含 `answer/citations/confidence/refuse_reason` 四个字段。
- 拒答时：
  - `answer` 返回拒答文案
  - `citations` 为空数组
  - `confidence = 0.0`
  - `refuse_reason` 非空

## citation 契约（前端可直接消费）
- `AnswerCitation`
  - `citation_id`
  - `chunk_id`
  - `doc_id`
  - `kb_id`
  - `section_path`
  - `snippet`
  - `score_final`
  - `source`
  - `citation`（透传 04 的 citation 原始字段）

说明：
- 前端可以直接使用 `citation_id + snippet + source + section_path` 渲染引用列表。
- 通过 `chunk_id/doc_id/kb_id` 可回链到检索与文档域。

## LLM Provider 可替换接口
- 位置：`backend/app/services/llm_provider.py`
- 抽象接口：`LLMProvider`
  - `provider_name`
  - `model_name`
  - `generate(request: LLMGenerateRequest) -> LLMGenerateResult`
- 默认实现：`MockLLMProvider`
  - 可离线运行
  - 输出可重复（便于测试）

## 拒答规则骨架
- 位置：`backend/app/services/refusal_policy.py`
- 策略：`RefusalPolicy.evaluate(...)`
- 基础规则：
  1. `hits` 为空 -> `QA_CONTEXT_EMPTY`
  2. `score_final >= min_score_threshold` 的证据片段数小于 `min_evidence_chunks` -> `QA_EVIDENCE_INSUFFICIENT`
  3. 其余场景允许回答

## 默认可运行流程（V1）
- 位置：`backend/app/services/answer_generation_service.py`
- 流程：
  1. 从 `retrieval_result.hits` 按 `score_final` 降序选取 `max_context_chunks`
  2. 执行 `RefusalPolicy`
  3. 若拒答：直接构造稳定结果
  4. 若可答：构建上下文块，调用 `LLMProvider.generate`
  5. 使用 `CitationBuilder` 拼接 `citations`
  6. 计算并返回 `confidence` 与最终结果
