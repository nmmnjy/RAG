## 统一评测输入契约
- Schema 位置：`backend/app/schemas/evaluation.py`
- 顶层输入：`OfflineEvaluationDatasetInput`
  - `dataset_id`
  - `dataset_version`
  - `description`
  - `runtime_policy`
    - `declared_real_mode`（可选，未设置时按环境自动推断）
    - `forbid_fallback_when_real_mode`（是否启用 real 禁止 fallback 门禁）
  - `cases[]`
- case 输入：`OfflineEvaluationCaseInput`
  - `case_id`, `case_name`, `query_text`
  - `structured_document`（直接使用 `01` 的 `StructuredDocument`）
  - `retrieve_config`（仅评测执行参数，不新增业务命中结构）
  - `answer_config`（仅评测执行参数）
  - `assertions`（规则型断言）
    - `min_answer_confidence`
    - `evidence_text`
    - `require_evidence_hit`

说明：
- 评测执行时会基于 `structured_document` 串联调用 02/03/04/05 骨架服务。
- `doc_id/kb_id/chunk_id/score_*` 等业务字段全部复用 00~05 冻结命名。

- 产物目录：`evaluation/reports/`
- 字段兼容策略：
  - 仅允许向后兼容新增字段，不允许删除或重命名已有字段。

## 发布门禁最小规则骨架
- 规则 schema：`ReleaseGateRule` / `ReleaseGateResult`
- 当前默认规则：
  - `gate_pass_rate_min_0_90`：总检查通过率 `>= 0.90`
  - `gate_parse_dimension_must_pass`：每个 case 的解析维度必须通过
  - `gate_retrieval_dimension_must_pass`：每个 case 的检索维度必须通过
  - `gate_answer_dimension_must_pass`：每个 case 的答案维度必须通过
  - `gate_answerable_evidence_hit_must_pass`：可答样本 `answer_evidence_hit_for_answerable` 必须通过
  - `gate_real_mode_forbid_fallback`：当 `runtime_policy.forbid_fallback_when_real_mode=true` 且 real 模式时，禁止 fallback
- 阻断逻辑：
  - 任一门禁失败 => `release_blocked = true`
  - 所有门禁通过 => `release_blocked = false`
- 阈值来源：
  - 默认 `gate_pass_rate_min=0.90`
  - 可由命令参数 `--gate-pass-rate-min` 覆盖，覆盖值会写入门禁断言（`assertion_result`）

## Real/Fallback 升级（第三轮）
- 目标：避免 real provider 静默降级到 mock。
- 检查：
  - real 模式下 fallback 是否发生（可观测）
  - fallback 发生时是否在报告中显式可见
- 门禁：
  - 通过 `runtime_policy.forbid_fallback_when_real_mode` 开启“real 禁止 fallback”
  - 若开启且 real 模式发生 fallback，则 `gate_real_mode_forbid_fallback` 失败并阻断发布
  - 若未开启，`gate_real_mode_forbid_fallback` 标记为 `skipped_not_enforced`

## 离线评测模块与本地执行
- 核心服务：`backend/app/services/offline_evaluator.py`
- CLI 入口：`backend/app/evaluation/run_offline_evaluation.py`
- 本地执行示例（在 `backend` 目录）：
  - `python -m app.evaluation.run_offline_evaluation --dataset ..\\evaluation\\datasets\\sample_v1\\manifest.json --write-stable-report`
  - `python -m app.evaluation.run_offline_evaluation --dataset ..\\evaluation\\datasets\\qa_demo_v1\\manifest.json --write-stable-report --gate-pass-rate-min 0.90`
- 命令行关键输出：
  - `check_pass_rate`
  - `release_blocked`
  - `answer_refuse_case_count`
  - `answer_evidence_hit_failed_count`
  - `report_path`
  - `stable_report_path`（启用 `--write-stable-report` 时）
