## 本地可演示一键检查流程（第二轮）
1. 前端构建：
- `.\infra\scripts\local-frontend.ps1 -Action build`
2. 后端关键测试：
- `.\infra\scripts\local-backend.ps1 -Action test -TestScope key`
3. 离线评测：
- `.\infra\scripts\local-evaluation.ps1 -Dataset qa_demo_v1`
4. 一键执行：
- `.\infra\scripts\local-acceptance.ps1 -EvalDataset qa_demo_v1`

## Real-Mode 一键联调验收（第三轮）
1. real 预检（必填变量 + real 语义校验）：
- `.\infra\scripts\preflight.ps1 -Environment test -Profile real -RealMode`
2. real 一键验收：
- `.\infra\scripts\local-real-acceptance.ps1 -Environment test -EvalDataset qa_demo_v1 -ForbidFallbackWhenRealMode`
3. real 评测单步执行（可选）：
- `.\infra\scripts\local-evaluation.ps1 -Dataset qa_demo_v1 -RealMode -ForbidFallbackWhenRealMode`

## 环境变量分层与最小必填（对齐 00/03/05）
- 基线最小集合（00）：
- `APP_ENV`、`APP_PORT`、`DB_URL`、`SUPABASE_URL`、`SUPABASE_KEY`、`LLM_API_KEY`、`EMBEDDING_MODEL`、`LOG_LEVEL`
- 向量化补充（03）：
- `EMBEDDING_PROVIDER`、`EMBEDDING_DIM`、`VECTOR_REPOSITORY`、`VECTOR_REPOSITORY_ENABLE_REAL`、`VECTOR_REPOSITORY_FALLBACK_TO_IN_MEMORY`
- 答案生成补充（05）：
- `LLM_PROVIDER`、`LLM_MODEL`、`LLM_PROVIDER_ENABLE_REAL`、`LLM_PROVIDER_FALLBACK_TO_MOCK`

## Real-Mode 验收判定标准
- 报告中 `case_reports[].output_summary.provider_runtime` 必须可见，且包含 `embedding` 与 `llm`。
- `gate_real_mode_forbid_fallback` 必须存在于 `gate_results`：
- 当启用 `forbid_fallback_when_real_mode=true` 时：
- `passed=true` 表示 real 模式未发生 fallback。
- `passed=false` 表示 real 模式发生 fallback，应阻断发布。
- 当未启用该策略时：
- 允许 `metric_value=skipped_not_enforced`，表示门禁存在但未强制。
