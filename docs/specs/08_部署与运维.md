# 08 部署与运维

## 文档状态
- 状态：已收敛（ops -> infra 已执行）
- 作用：供前后端线程统一参考部署与环境约束

## 当前固定边界
- 本模块负责部署拓扑、环境规划、监控告警和回滚策略。
- 本模块不负责业务功能实现。
- 环境变量、日志和链路追踪必须对齐 `00` 规范。

## 已落地目录（统一基线）
- 部署总览与目录说明：`infra/README.md`
- 拓扑：`infra/topology/deployment-topology.md`
- 环境模板：`infra/environments/.env.shared.example`、`infra/environments/.env.dev.example`、`infra/environments/.env.test.example`、`infra/environments/.env.prod.example`
- 本地演示环境模板：`infra/environments/.env.local-demo.example`
- 环境说明：`infra/environments/README.md`
- 前端部署：`infra/vercel/vercel.json`、`infra/vercel/README.md`、`infra/vercel/deploy-frontend.ps1`
- 后端部署：`infra/supabase/Dockerfile.fastapi`、`infra/supabase/README.md`、`infra/supabase/deploy-backend.ps1`
- 监控告警：`infra/monitoring/observability-baseline.md`
- 发布与回滚：`infra/runbooks/release-checklist.md`、`infra/runbooks/rollback.md`、`infra/runbooks/incident-checklist.md`、`infra/runbooks/local-demo-runbook.md`
- 运维脚本：`infra/scripts/preflight.ps1`、`infra/scripts/health-check.ps1`、`infra/scripts/local-frontend.ps1`、`infra/scripts/local-backend.ps1`、`infra/scripts/local-evaluation.ps1`、`infra/scripts/local-acceptance.ps1`

## 目录职责说明
- `infra/vercel/`：前端 Vercel 配置与发布脚本。
- `infra/supabase/`：后端容器部署骨架与 Supabase 接入说明。
- `infra/environments/`：环境模板与配置注入规范。
- `infra/scripts/`：预检、健康检查等通用脚本。
- `infra/topology/`：部署拓扑设计。
- `infra/monitoring/`：监控指标、告警分级与日志基线。
- `infra/runbooks/`：发布、回滚、故障处置手册。

## 与 00 基线的一致性结论
- 目录主干已统一为 `infra/`，不再保留 `ops/` 双目录基线。
- 后端部署目录采用 `infra/supabase/`，作为用户要求中“`infra/backend` 或等价目录”的等价实现。

## 本地可演示一键检查流程（第二轮）
1. 前端构建：
- `.\infra\scripts\local-frontend.ps1 -Action build`
2. 后端关键测试：
- `.\infra\scripts\local-backend.ps1 -Action test -TestScope key`
3. 离线评测：
- `.\infra\scripts\local-evaluation.ps1 -Dataset qa_demo_v1`
4. 一键执行：
- `.\infra\scripts\local-acceptance.ps1 -EvalDataset qa_demo_v1`

## 环境变量分层与最小必填（对齐 00/03/05）
- 基线最小集合（00）：
- `APP_ENV`、`APP_PORT`、`DB_URL`、`SUPABASE_URL`、`SUPABASE_KEY`、`LLM_API_KEY`、`EMBEDDING_MODEL`、`LOG_LEVEL`
- 向量化补充（03）：
- `EMBEDDING_PROVIDER`、`EMBEDDING_DIM`、`VECTOR_REPOSITORY`、`VECTOR_REPOSITORY_ENABLE_REAL`、`VECTOR_REPOSITORY_FALLBACK_TO_IN_MEMORY`
- 答案生成补充（05）：
- `LLM_PROVIDER`、`LLM_MODEL`、`LLM_PROVIDER_ENABLE_REAL`、`LLM_PROVIDER_FALLBACK_TO_MOCK`
