# 06 前端交互与管理后台

## 文档状态
- 状态：已补充（第一版）
- 作用：供后端接口线程和 UI 线程引用

## 当前固定边界
- 本模块负责用户问答页面、管理后台页面、前端状态流和组件分层。
- 本模块不负责后端业务逻辑实现。
- 页面数据结构必须对齐共享字段命名与统一响应结构。

## 路由与页面骨架
- 用户侧：
  - `/qa`：问答主流程页
  - `/history`：问答历史页
  - `/citations/[citationId]`：引用详情页
- 管理侧：
  - `/admin/kbs`：知识库管理
  - `/admin/documents`：文档管理
  - `/admin/tasks`：任务状态
  - `/admin/logs`：日志看板

## 页面状态流
- 主流程状态字段：
  - `upload_state`：`idle/uploading/uploaded/failed`
  - `parse_state`：`idle/parsing/parsed/failed`
  - `index_state`：`idle/indexing/indexed/failed`
  - `retrieve_state`：`idle/retrieving/retrieved/empty/failed`
  - `answer_state`：`idle/answering/answered/refused/failed`
- 空态与异常态：
  - 检索空态：`retrieve_state = empty`
  - 拒答态：`answer_state = refused`
  - 任意阶段失败：`* = failed`

## 接口类型定义（冻结）
- 统一成功响应（00 规范）：
  - `{ code, message, data, request_id, trace_id, ts }`
- 统一错误响应（00 规范）：
  - `{ code, message, details?, request_id, trace_id }`
- 禁止使用第二套响应协议（包括 `status/data/error/meta`）。

## 关键字段命名（对齐 PRD）
- 文档：`doc_id`, `kb_id`, `source`, `format`, `version`, `status`
- 分块：`chunk_id`, `doc_id`, `content`, `token_count`, `section_path`
- 检索：`chunk_id`, `score_vector`, `score_keyword`, `score_final`, `citation`
- 问答：`answer`, `citations`, `confidence`, `refuse_reason`

## 组件分层与复用规则
- `app`：路由与页面壳层。
- `features`：按业务域组织页面逻辑与数据访问。
- `components/ui`：基础 UI 组件（Button/Card/Badge）。
- `components/layout`：布局区块组件。
- `types`：共享契约类型，统一由 00 规范驱动。
- `lib`：HTTP 封装、端点常量、工具函数。
