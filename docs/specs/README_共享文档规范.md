# 共享文档规范

## 目标
从现在开始，每个线程的关键产出必须落到仓库中的共享文档，作为跨线程协作的唯一事实来源。

## 文档分层
- `docs/specs`：对外共享规范，供其他线程直接引用。
- `docs/tasks`：模块任务清单，定义目标、边界、任务与验收。
- `docs/changes`：模块实施记录，记录当前实现、变更、风险与下一步。

## 必须文档化的内容
- 影响其他模块的字段、接口、错误码、日志、环境变量变更。
- 模块进入编码后的重要实现结论。
- 风险项、阻塞项、待主线程确认项。

## 生效规则
- 只有写入仓库文档的内容，才视为正式生效。
- 主线程只认文档，不认聊天记录。
- 若规范与实现不一致，以 `docs/specs` 为准。

## 推荐命名
- 共享规范：`docs/specs/{模块编号}_{模块名}.md`
- 实施记录：`docs/changes/{模块编号}_实施记录.md`
